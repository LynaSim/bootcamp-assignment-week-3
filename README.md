Objective: Migrating a Site to Bootstrap.

I chose to migrate my week 2 project (https://lynasim.github.io/bootcamp-assignment-week-2/index.html) to Bootstrap, while adding a few more pages that I thought were important for a café website: a Find Us page and a Menu page.

I've used the following Bootstrap components:
- navbar with dropdown
- carousel
- card
- accordion
- button

I've included a jQuery widget: a dialog box on the homepage, and styled it using Bootstrap utilities classes.
